# Portfolio recruiter polish

## Goal
Make the existing Astro portfolio faster to understand for backend and industrial IoT recruiters while preserving its monochrome terminal identity and evidence-based claims.

## Scope
- Rewrite hero and work copy around contribution and system scope without inventing sensitive metrics.
- Make project hierarchy and featured-project proof points easier to scan.
- Clarify theme toggle semantics and improve hero spacing.
- Derive organization contribution range from `org-summary.json`.
- Correct README language count and align deployment documentation with the canonical custom domain.

## Constraints
- Keep Astro, Tailwind CSS, static output, EN/ID localization, and existing routes.
- Do not add unverified performance figures, screenshots, or dependencies.
- Do not expose private repository names or internal project details.

## Acceptance criteria
- Homepage hero communicates role and contribution in one scan.
- Work bullets use action plus context plus result/scope.
- Featured project exposes evidence-backed proof points without marketing claims.
- Theme toggle states what action it performs and remains keyboard accessible.
- Organization date range is generated from JSON data.
- README accurately says the site supports EN and ID and documents the canonical deployment domain.
- Build and existing verification script pass.
